# User Activation

Reduce the work between a new user's arrival and their first meaningful result.

## Understand

Inspect the current signup and product flows. Define a concrete activation event from the product's purpose and available evidence; do not assume every product needs a tutorial or checklist.

## Improve the path

- Ask for information when it becomes necessary.
- Explain confirmation emails and offer resend/recovery paths.
- Preserve authentication and security requirements unless a deliberate change is authorized.
- Use empty states to explain the next useful action.
- Prefer doing the real task over a mandatory tooltip tour.
- Use progress or a checklist only when it makes a genuinely multi-step task easier.
- Keep sample data clearly labeled and removable.
- Make help and cancellation easy to find.

## Cancellation

Provide a clear route to cancel and explain when access ends. Keep reasons optional and any retention offer easy to bypass. Verify the real provider state changes.

Check applicable current consumer requirements before making legal claims; the status and coverage of particular cancellation rules can change.

## Verify

Use a fresh test account through signup, activation, recovery, and cancellation where applicable. Check phone widths, keyboard use, errors, and persisted progress.

Measure activation only when a tracking purpose and appropriate privacy controls exist. Explain which change reduced friction and what evidence remains to be collected.
