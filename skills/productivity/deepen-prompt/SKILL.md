# Deepen Prompt

Improve a task brief so the intended result and verification are clear.

## Method

1. Identify the user's outcome and the gaps that could materially weaken execution.
2. Identify the primary materials needed: existing code, design reference, raw data, or authoritative documentation.
3. Name concrete methods and available tools that fit this task.
4. Define an external check: a working flow, test, measurement, or comparison to the requirements.
5. Rewrite the prompt in the user's language and preserve its constraints and deliverable.

Keep the revised prompt copyable and explain only the few additions that matter. Do not add features, a research program, or a mandatory planning ceremony.

When the user asked to do work, carry out the work. Do not silently replace the request with prompt coaching.
