# Structured Data

Read before adding JSON-LD to a public page.

Choose a schema type that accurately describes visible content: Organization, LocalBusiness, Article, Product with a real offer, Event, or BreadcrumbList where appropriate.

- Use real names, URLs, prices, availability, dates, and images.
- Keep identities consistent through stable absolute URLs or @id values.
- Do not invent ratings, testimonials, reviews, business addresses, or product claims.
- Validate JSON syntax and the current required fields for the intended feature.
- Render metadata through the framework's supported route/head APIs.
- Serialize untrusted values safely when embedding JSON in HTML.
- Match visible page content and current search feature eligibility.

Rich-result eligibility does not guarantee a rich result or ranking benefit. Check current [Google structured data guidance](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data) and [schema.org](https://schema.org/) before asserting support for a feature.
